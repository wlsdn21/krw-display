# GitHub 공개용 문구

## 저장소 설명

웹페이지의 USD·USDT·USDC 금액을 실시간 원화(KRW) 기준으로 함께 보여주는 Chrome 확장 프로그램

## About 문구 예시

해외 거래소와 웹페이지의 달러 가격을 한국 원화로 빠르게 읽을 수 있도록, 페이지 텍스트 옆에 KRW 기준 금액을 자연스럽게 병기하는 Chrome 확장 프로그램입니다.

## 첫 릴리스 제목 예시

`v1.3.6 - GitHub 공개용 정리 및 업데이트 배너 개선`

## 릴리스 본문 예시

```md
## 변경 사항

- GitHub 공개용 문서와 README 정리
- 팝업 버전 표시를 manifest 기준으로 자동화
- 사이트 목록 favicon 표시 개선
- 업데이트 배너 오탐 방지 로직 보정

## 설치 방법

1. 아래 ZIP 파일을 내려받습니다.
2. 압축을 해제합니다.
3. Chrome에서 `chrome://extensions`로 이동합니다.
4. `개발자 모드`를 켭니다.
5. `압축해제된 확장 프로그램을 로드합니다`를 눌러 폴더를 선택합니다.

## 참고

- 이 확장은 Chrome Web Store 배포본이 아니므로 자동 업데이트되지 않습니다.
- 새 버전이 있으면 팝업 상단에 업데이트 배너가 표시됩니다.
```

## 공개 전 체크

- 저장소 이름이 영문 slug인지 확인
- `README.md`가 GitHub 첫 화면에서 자연스럽게 보이는지 확인
- `manifest.json` 버전과 릴리스 태그가 일치하는지 확인
- 공개하고 싶지 않은 개인 정보나 링크가 남아 있지 않은지 확인
