# 원화표시기

웹페이지에 표시된 `USD`, `USDT`, `USDC` 금액을 한국 원화(`KRW`) 기준으로 함께 보여주는 Chrome 확장 프로그램입니다.

## 주요 기능

- 웹페이지의 달러/스테이블코인 금액을 자동으로 KRW로 병기
- `국제 환율`, `업비트 USDT`, `업비트 USDC`, `사용자 지정 환율` 중 기준 선택
- 억/조 단위 표시와 소수점 자릿수 설정
- 사이트별 적용 또는 전체 사이트 적용 모드
- 팝업에서 현재 환율 소스, 마지막 업데이트, 자동 갱신 상태 확인

## 설치 방법

1. 이 저장소를 내려받거나 ZIP으로 받습니다.
2. Chrome에서 `chrome://extensions`로 이동합니다.
3. 우측 상단 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 눌러 이 폴더를 선택합니다.

## 권한

- `storage`
  - 환율 소스, 사이트 목록, 표시 옵션을 브라우저에 저장합니다.
- `alarms`
  - 환율을 주기적으로 갱신합니다.
- 웹사이트 접근 권한
  - 현재 페이지의 통화 텍스트를 찾아 KRW 표시를 덧붙입니다.

## 개발

핵심 파일은 아래와 같습니다.

- `content.js`: 페이지 내 통화 텍스트 감지 및 KRW 병기
- `background.js`: 환율 조회와 주기적 갱신
- `popup.html`, `popup.css`, `popup.js`: 확장 팝업 UI
- `manifest.json`: 확장 권한과 진입점 설정

변경 내역은 `CHANGELOG.md`, 웹스토어 제출용 문서는 `release/` 폴더에 정리되어 있습니다.

## 테스트

현재 별도 자동 테스트 인프라는 없습니다. 변경 후에는 아래 수동 검증을 권장합니다.

- Binance, Hyperliquid 같은 주요 사이트에서 USD/USDT 변환 확인
- 환율 소스 전환 확인
- 사이트별 적용 / 전체 사이트 적용 확인
- 팝업에서 마지막 업데이트와 상태 표시 확인
