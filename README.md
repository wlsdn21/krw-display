# 원화표시기

원화표시기는 웹페이지에 표시된 `USD`, `USDT`, `USDC` 금액을 한국 원화(`KRW`) 기준으로 함께 보여주는 Chrome 확장 프로그램입니다.

해외 거래소, 트레이딩 플랫폼, 뉴스 페이지에서 달러 가격을 볼 때 매번 환산하지 않아도 되도록, 페이지 텍스트 옆에 자연스럽게 원화 기준 값을 병기합니다.

## 주요 기능

- 웹페이지의 달러/스테이블코인 금액을 자동으로 KRW로 병기
- 바이낸스의 주요 메뉴와 거래 화면을 국내 투자자가 익숙한 거래 용어로 표시
- 바이낸스 선물 수량 단위 메뉴에 KRW를 추가하고 원화 입력값을 USDT/USDC로 내부 환산
- `국제 환율`, `업비트 USDT`, `업비트 USDC`, `사용자 지정 환율` 중 기준 선택
- `억`, `조` 단위 표시와 소수점 자릿수 설정
- 선택한 사이트만 적용하거나 모든 사이트에 적용
- 팝업에서 현재 환율 소스, 마지막 업데이트, 갱신 상태 확인
- GitHub 기준 새 버전이 있으면 팝업 상단에서 업데이트 배너 안내

## 이런 식으로 동작합니다

- `$100` -> `$100 (₩130,000)` 형태로 표시
- `1,250 USDT` -> `1,250 USDT (₩...)` 형태로 표시
- `100달러` -> `100달러 (₩...)` 형태로 표시
- `50억 달러` -> `50억 달러 (₩...)` 형태로 표시

바이낸스 한국어 표시는 팝업의 `바이낸스 한국어` 스위치로 원화 변환과 별도로 켜거나 끌 수 있습니다. 코인명, 티커, 숫자, 주문값과 법률 고지문은 오역이나 거래 혼동을 피하기 위해 원문을 유지합니다.

실제 표시는 선택한 환율 소스와 단위 설정에 따라 달라집니다.

## 설치 방법

1. 이 저장소를 ZIP으로 내려받거나 `git clone`으로 복제합니다.
2. Chrome에서 `chrome://extensions`로 이동합니다.
3. 우측 상단의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누른 뒤 이 폴더를 선택합니다.

## 업데이트 방식

이 확장은 Chrome Web Store 배포 버전이 아니라, GitHub 소스 기반 `압축해제된 확장 프로그램` 방식으로 사용하는 것을 기준으로 합니다.

- Chrome Web Store처럼 자동 업데이트되지는 않습니다.
- 새 버전이 GitHub에 올라오면 팝업 상단에 업데이트 배너가 표시됩니다.
- 배너 버튼을 누르면 최신 ZIP 다운로드 페이지로 이동할 수 있습니다.

## 권한과 외부 요청

- `storage`
  - 환율 소스, 사이트 목록, 표시 옵션을 브라우저에 저장합니다.
- `alarms`
  - 환율 및 업데이트 상태를 주기적으로 확인합니다.
- `raw.githubusercontent.com`
  - GitHub에 올라간 최신 버전 정보를 확인해 업데이트 배너를 표시합니다.
- 환율 API
  - `open.er-api.com`, `api.exchangerate-api.com`, `api.exchangerate.host`, `api.manana.kr`, `api.upbit.com`
- 웹사이트 접근 권한
  - 현재 페이지의 통화 텍스트를 찾아 KRW 표시를 덧붙입니다.

사이트 목록에서 favicon을 표시할 때는 Google favicon 서비스 이미지 요청이 발생할 수 있습니다.

## 프로젝트 구조

- `content.js`: 페이지 내 통화 텍스트 감지 및 KRW 병기
- `binance-ko-translations.js`: 검토된 바이낸스 거래 용어와 동적 문구 규칙
- `binance-ko.js`: 바이낸스 화면에 번역을 적용하고 원문을 복원
- `background.js`: 환율 조회, 주기적 갱신, 업데이트 체크
- `popup.html`, `popup.css`, `popup.js`: 팝업 UI
- `manifest.json`: 확장 권한과 진입점 설정
- `CHANGELOG.md`: 변경 이력
- `release/`: 릴리스/배포 관련 문서

## 개발 메모

- 기본 개발 브랜치는 `main`이 아니라 별도 작업 브랜치 기준으로 운영하는 것을 권장합니다.
- 릴리스할 때는 `manifest.json` 버전, 변경 이력, GitHub 릴리스 노트를 함께 정리하는 방식이 안전합니다.
- 팝업에 표시되는 버전은 `manifest.json` 버전을 기준으로 자동 반영됩니다.

## 테스트

번역 용어 자동 검증은 `node test-binance-ko-translations.js`로 실행합니다.
그 밖의 기능은 아래 수동 검증을 권장합니다.

- Binance, Hyperliquid 같은 주요 사이트에서 USD/USDT 변환 확인
- Binance의 마켓·거래 화면 전환 후 한국어 표시 및 끄기 시 영어 복원 확인
- `100달러`, `1,250 달러`, `$100`, `50억 달러` 같은 표기 변환 확인
- 환율 소스 전환 확인
- 선택 사이트 적용 / 전체 사이트 적용 확인
- 팝업의 업데이트 배너 표시 조건 확인
